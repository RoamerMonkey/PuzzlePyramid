A quick puzzle and hidden object game where your goal is to fully complete the Puzzle Pyramid. Each side of the Pyramid has a tricky puzzle and a colorful hidden object scene to solve; can you finish the Pyramid?

I created this game using Godot in four-ish weeks: I started at Jan 10 and finished by February 3. The dialogue is powered by Dialogic.

I completed the game design, artwork, and some programming by myself. I heavily used YouTube tutorials for help with the coding. I used royalty-free music from Purple Planet and sound effects from Freesound.
